## Copy and paste

| Action | Shortcut |
| --- | --- |
| Copy the selection | <kbd>Ctrl</kbd>+<kbd>C</kbd> |
| Paste where the camera aims | <kbd>Ctrl</kbd>+<kbd>V</kbd> |
| Paste at the original position | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> |
| Move the selection where the camera aims | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> |
| Duplicate the selection | <kbd>Ctrl</kbd>+<kbd>D</kbd>, the same as copy then paste in place |
| Delete the selection | <kbd>Del</kbd> |

Copying works between any two level editors, even between different games: open the source level and the destination level in separate tabs or side by side, copy in one, paste in the other. Everything the objects need, models, textures, templates, splines, comes along. Objects are highlighted while they are being copied.

Pasted objects land where the central dot is aiming. The placement uses a raycast against the scene, so objects sit on top of the object that is currently being looked at, and pasting can collide with [dynamic clips](/level-editor/special-objects/dynamic-clips/). Collectibles are pasted slightly above the ground so they do not sink into it.

### Special cases

- **Script triggers.** Copying objects without their parent trigger adds the copies to the original trigger; copying objects together with their trigger creates a new trigger for the copies. See [Script triggers](/level-editor/special-objects/script-triggers/).
- **Prefabs.** Clicking a prefab child once selects the whole instance (if it doesn't have too many children), which you can copy as a group. See [Prefab instances](/level-editor/special-objects/prefab-instances/).
- **Spawners and templates.** Pasting a spawner copies its hidden template as well, and each copy gets its own template so that later edits do not leak between copies. See [Spawner templates](/level-editor/special-objects/spawner-templates/).
- **Cameras and camera boxes** can be copied like any other object. Spline cameras get their own copy of the spline.
- **Between games.** Objects from CTR:NF need to be NST-compatible. See [CTR:NF support](/level-editor/ctr-nf-support/).

## Undo and redo

Added in v1.39. Use <kbd>Ctrl</kbd>+<kbd>Z</kbd> to undo, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> to redo.

| Can be undone | Cannot be undone yet |
| --- | --- |
| Selecting objects | Copying and pasting objects |
| Moving, rotating and scaling objects | Creating objects |
| | Deleting objects |
| | Editing components |

For the actions that cannot be undone, rely on [backups](/level-editor/save-play-and-backups/#backups): <kbd>Ctrl</kbd>+<kbd>L</kbd> creates one automatically before every save and launch, and `Backup → Restore` brings the level back.
