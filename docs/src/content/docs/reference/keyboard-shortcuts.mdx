The **Controls** panel in the left column of the level editor shows the same list at any time.

## Level editor

### Camera

| Action | Control |
| --- | --- |
| Move | <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> |
| Rotate | Right mouse button |
| Move faster | <kbd>Shift</kbd> |
| Move down / up | <kbd>Q</kbd> / <kbd>E</kbd> |
| Zoom in / out | Mouse wheel |

### Selection

| Action | Control |
| --- | --- |
| Select objects | Left click, or left click and drag for a box selection |
| Select parent or child objects | Click the object again |
| Add to or remove from the selection | <kbd>Shift</kbd> + left click |
| Align and snap the selected crates | <kbd>Left Alt</kbd> |
| Unselect everything | <kbd>Escape</kbd> |
| Collapse the object tree | <kbd>Escape</kbd> twice |
| Select all objects | Right-click, `Select All` |

### Objects

| Action | Shortcut |
| --- | --- |
| Create objects | Right click |
| Copy the selection | <kbd>Ctrl</kbd>+<kbd>C</kbd> |
| Paste | <kbd>Ctrl</kbd>+<kbd>V</kbd> |
| Paste at the original position | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> |
| Move the selection | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> |
| Duplicate the selection | <kbd>Ctrl</kbd>+<kbd>D</kbd> |
| Delete the selection | <kbd>Del</kbd> |

### Gizmos

| Action | Shortcut |
| --- | --- |
| Translate mode | <kbd>Ctrl</kbd>+<kbd>E</kbd> |
| Rotate mode | <kbd>Ctrl</kbd>+<kbd>R</kbd> |
| Scale mode | <kbd>Ctrl</kbd>+<kbd>T</kbd> |
| Toggle world / object space | <kbd>Ctrl</kbd>+<kbd>G</kbd> |
| Snap to the grid | Hold <kbd>Shift</kbd> while dragging |
| Undo | <kbd>Ctrl</kbd>+<kbd>Z</kbd> |
| Redo | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> |

### Save and launch

| Action | Shortcut |
| --- | --- |
| Save | <kbd>Ctrl</kbd>+<kbd>S</kbd> |
| Backup, save and launch | <kbd>Ctrl</kbd>+<kbd>L</kbd> |
| Save as... | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> |
| Reload the level | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> |
| Open a level or archive | <kbd>Ctrl</kbd>+<kbd>O</kbd> |

### Panels

| Action | Control |
| --- | --- |
| Edit a numeric field like a slider | Click and drag; hold <kbd>Shift</kbd>, <kbd>Ctrl</kbd> or <kbd>Alt</kbd> to change the speed |
| Type a value | Double-click the field |
| Select several components or list items | Click and drag, or <kbd>Shift</kbd>+click; <kbd>Ctrl</kbd>+click adds or removes one item |
| Remove list items | <kbd>Del</kbd> |
| Add list items, or open the context menu | Right-click |
| Focus an item in the scene | Double-click |

## Archive editor

| Action | Shortcut |
| --- | --- |
| Save and overwrite the archive | <kbd>Ctrl</kbd>+<kbd>S</kbd> |
| Save as... | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> |
| Open an archive | <kbd>Ctrl</kbd>+<kbd>O</kbd> |
| Delete the selected file, or the selected object in the IGZ editor | <kbd>Del</kbd> |
| File and object actions | Right-click |
