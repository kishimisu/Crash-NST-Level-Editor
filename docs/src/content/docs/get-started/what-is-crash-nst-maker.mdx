Crash NST Maker is an open-source **mod manager and level editor** for *Crash Bandicoot N. Sane Trilogy* on PC/Linux. 

You can use it to **launch custom levels**, export assets (audio, textures, 3D models...) and edit game archives.

It is the successor of [The Apprentice](https://github.com/kishimisu/Crash-NST-Modding-Tool), an earlier proof of concept that I made to understand how the game works and how it could be modded. This version was rebuilt from scratch in C# with a focus on advanced level editing, performance and stability.

## Who is it for?

| For | What you can do |
| --- | --- |
| Players | Use the **Main Menu** to launch community levels and custom hubs, apply and remove mods, start the game at any level. |
| Creators | Use the **Level Editor** to create levels from scratch or from an existing level, edit them in a 3D scene view, and launch the game directly into your level. |
| Advanced users | Use the **Archive Editor** to open any `.pak` archive, edit the IGZ and Havok files inside, preview or extract models, textures, materials and audio. |
