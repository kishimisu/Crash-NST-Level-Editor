## Requirements

- **Windows 64-bit** (or [Wine](https://www.winehq.org/) if you're using **Linux**).
- **An original copy of Crash Bandicoot N. Sane Trilogy for PC**, installed through Steam or Xbox Game Pass.

## Download the prebuilt executable

<Steps>

1. Open the [Releases page](https://github.com/kishimisu/Crash-NST-Level-Editor/releases) on GitHub and download the executable attached to the latest release (`Crash-NST-Maker-<version>.exe`).

2. Put the file anywhere you like. It is a single self-contained executable: there is nothing to install.

3. Run it. The [main menu](/get-started/first-launch/) opens. The tool looks for your game installation; if it is not found, use the `File` menu of the main menu to set the game path.

</Steps>

:::note[Antivirus false positives]
Some antivirus software may report a false positive for the prebuilt executable. This tool runs entirely offline and never accesses the network. Alternatively, you can [build the application yourself](#build-from-source) from source as described below.
:::

## Updating

Check for new versions on the [Releases page](https://github.com/kishimisu/Crash-NST-Level-Editor/releases). You can keep multiple versions on your PC in case you encounter an issue with an update.

## Crash logs

When the application hits an unhandled error it writes the details to a log file. Condiser attaching it when you ask for help on Discord or open a GitHub issue.

## Uninstalling

Delete the executable. If you applied mods with the Mod Manager and want to uninstall them, click **Unmod game** first.
To clear any data cached by the editor such as object library previews or automatic backups, remove the storage folder located at: 

- `C:\Users\<username>\AppData\Local\NST_Modding_Tool`

## Build from source

You need the [Microsoft .NET SDK 9.0](https://dotnet.microsoft.com/en-us/download/dotnet/9.0). Then:

```bash
git clone https://github.com/kishimisu/Crash-NST-Level-Editor.git
cd Crash-NST-Level-Editor
dotnet run
```

(Optional) To build an optimized self-contained executable, use:

```bash
dotnet publish .\NST.csproj -c Release -r win-x64 --self-contained true \
  /p:PublishSingleFile=true \
  /p:IncludeNativeLibrariesForSelfExtract=true \
  /p:IncludeAllContentForSelfExtract=true \
  /p:EnableCompressionInSingleFile=true
```

The source is organised in a few folders under `src/`: 
- `Alchemy/` (`.pak` archives, `.igz` files and Alchemy objects)
- `Havok/` (`.hkx` files and Havok objects)
- `Editor/` (the application),
- `Utils/`

See [Alchemy API](/archive-editor/alchemy-api/) if you want to script the archives yourself.
