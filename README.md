# Crash NST Maker

A mod manager and level editor for Crash NST and CTR:NF (WIP)

<img src="assets/readme/editor.jpg" alt="Crash NST Maker" width="750"/>

### Features

- Create and play custom levels
- Import objects from any level
- Manage and create mods
- Export 3D models, textures, audio
- Advanced tools for exploring and editing game files
